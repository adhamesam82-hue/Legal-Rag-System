# التذاكر

٢٢ تذكرة قابلة للتنفيذ + ٤ ملاحم محجوبة على قرار، مستخرجة من مراجعة جاهزية المشروع.

## الرفع إلى GitHub

السكربت لم يُشغَّل بعد — `gh` غير مثبّت على الجهاز الذي وُلِّدت منه التذاكر.

```bash
# مرة واحدة
winget install GitHub.cli     # أو: brew install gh
gh auth login

# ثم
bash tickets/import-to-github.sh
```

ينشئ التسميات والـ milestones والتذاكر الـ ٢٦. آمن للتشغيل مرة واحدة فقط —
إعادة تشغيله تنشئ نسخًا مكررة.

للتحقق بعدها:

```bash
gh issue list --repo adhamesam82-hue/Legal-Rag-System --limit 40
```

### نقطتا تزامن

- **T-017** (تبويب الجلسات) مشتركة — تبدأ بعد **T-013** و**T-014**

### قواعد تمنع التصادم

1. **T-005 و T-006 و T-015 كلها في كتالوجات الترجمة** — شخص واحد، بالترتيب.
2. **T-018 يعيد كتابة `practice_api.py` بالكامل** — لا يبدأ قبل أن تُدمج
   T-001 و T-002 و T-003.
3. **فرع لكل تذكرة**: `t-001-close-llm-routes` ← PR ← دمج.
4. **T-001 أولًا مهما كان** — الثغرة مفتوحة الآن على الإنترنت.

## تحذير يتكرر في أكثر من تذكرة

**إخفاء الشاشة لا يقفل المسار.** T-007 تخفي شاشات الذكاء الاصطناعي من التنقل،
لكن `/api/ask` يظل مفتوحًا للإنترنت حتى تُنفَّذ T-001. الاثنتان معًا أو لا شيء.
