# التذاكر

٢٢ تذكرة قابلة للتنفيذ + ٤ ملاحم محجوبة على قرار، مستخرجة من مراجعة جاهزية المشروع.

## الرفع إلى GitHub

السكربت لم يُشغَّل بعد — `gh` غير مثبّت على الجهاز الذي وُلِّدت منه التذاكر.

```bash
# مرة واحدة
winget install GitHub.cli     # أو: brew install gh
gh auth login

# ثم
bash tickets/import-to-github.sh
```

ينشئ التسميات والـ milestones والتذاكر الـ ٢٦. آمن للتشغيل مرة واحدة فقط —
إعادة تشغيله تنشئ نسخًا مكررة.

للتحقق بعدها:

```bash
gh issue list --repo adhamesam82-hue/Legal-Rag-System --limit 40
```

## القواعد التي تمنع التصادم

**١. الهجرات بالترتيب، واحدة في كل مرة.** الأرقام `0021` ← `0025` محجوزة بالتتابع. فرعان
يضيفان `0021_*.sql` يندمجان نظيفَين ثم يفشلان على الصندوق. أعلن الرقم الذي أخذته عند فتح الـPR.

**٢. الخلفية قبل الواجهة، دائمًا.** T-029 لا تبدأ قبل دمج T-024، و T-031 لا تبدأ قبل T-025،
و T-033 قبل T-026، و T-034 قبل T-027 و T-028. المبدأ في هذا المشروع أن **لا واجهة تكذب** —
فلا شاشة تُبنى على عمود غير موجود.

**٣. تذكرتان على نفس الملف لا تبدآن معًا:**

| الملف | التذاكر | الترتيب |
|---|---|---|
| `web/components/matter/DashboardTab.tsx` | T-029 · T-030 | T-029 تُدمج أولًا |
| `web/app/documents/page.tsx` | T-031 · T-032 | T-031 تُدمج أولًا |
| `web/app/settings/page.tsx` | T-034 وحدها | — |
| `web/lib/i18n/catalogs/enums.ts` | T-023 وحدها | — |

**٤. T-035 آخر شيء.** تلمس كل الشاشات، وبدؤها قبل استقرارها يعني تعارضًا في كل ملف.

**٥. T-028 و T-036 مستقلّتان** ويصلحان لملء أي فراغ في الجدول بلا انتظار.

## تداخل مع تذاكر سابقة

**T-016 نُفِّذت فعلًا** ولم تكن تنتظر: [الهجرة 0010](../migrations/0010_egyptian_litigation_shape.sql)
أضافت `criminal` و `administrative` و `execution` و `arbitration`، فصار `matter_type` **عشر قيم
لا ستًّا**. §١٫١ من الوثيقة تقول ستًّا استنادًا إلى 0006 وحدها، وهذا قديم.

**T-023 تبني على ذلك** لا تكرّره: تضيف الأربع الناقصة فعلًا (`civil`, `commercial`,
`real_estate`, `intellectual_property`) و `other`، وتضيف تخصصات المكتب، **وتغلق فجوة قائمة**:
حرفيّة `Literal` في [_shared.py:114](../src/legalrag/practice_routes/_shared.py:114) ما زالت
ستّ قيم بينما القاعدة تقبل عشرًا، فأربعة أنواع تقبلها القاعدة يرفضها الـAPI بـ 422 اليوم.

**T-026 تكمل T-021** ولا تلغيها: T-021 (ضريبة على مستوى الفاتورة) نُفِّذت في
[الهجرة 0012](../migrations/0012_invoice_tax.sql)، و T-026 تنقل الضريبة إلى مستوى البند وتضيف
الملاحظات.

| البند | لماذا | أين |

عرضها**: يظنّ المحامي أن ملفًا حذفه قابل للاسترجاع وهو ليس كذلك.
