# T-010 · توصيل شاشة المستخدمين بالـ API

**الدفعة ١ — تسمية وتوصيل** · تقدير **1ي** · مقترح لـ **frontend**

**ملفات متوقعة:** `web/app/settings/users/page.tsx` · `web/lib/api.ts`

---

## المشكلة
الشاشة **وهمية بالكامل**: أربعة أشخاص مزيفين ودعوتان مزيفتان، وكل الأزرار
فارغة (`onClick: () => {}`). مالك مكتب سيفتحها ويرى أربعة غرباء كأنهم فريقه.

**والباك إند موجود ومختبَر:**
- `GET /api/orgs/{id}/members`
- `POST /api/orgs/{id}/invites`
- `DELETE /api/orgs/{id}/members/{clerk_user_id}`

⚠️ **تغيير الدور لا endpoint له أصلًا** — يُخفى الخيار أو تُفتح تذكرة له.

## معايير القبول
- [ ] القائمة من `GET /members` لا من مصفوفة ثابتة
- [ ] الدعوة تستدعي `POST /invites` وتظهر في المعلّقة
- [ ] الإزالة تستدعي `DELETE` وتحدّث القائمة
- [ ] حالات التحميل والخطأ والقائمة الفارغة
- [ ] خيار «تغيير الدور» مخفي حتى يوجد له endpoint
